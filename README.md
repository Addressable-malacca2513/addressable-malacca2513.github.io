# Portfolio

One file, no build step. Open `index.html` in a browser and it works.

## Make it yours
1. Replace every instance of "Sushmita" with your name (nav logo, ID card, footer, `<title>`).
2. Add your photo at `assets/profile.jpg` — portrait crop, about 800×1000. It's used in the hero and on the ID card.
3. Add `assets/resume.pdf` so the Resume button downloads something.
4. Edit the Projects, Skills and Certifications sections. Delete anything that isn't true.
5. Update the email, GitHub and LinkedIn links in the Contact section.
6. Connect the form: make a free form at formspree.io and paste your endpoint into the `action=` of `<form id="contactForm">`.

## Colors
All the colors live in the `:root` block at the top of the `<style>` tag. Change `--red` and the whole site follows.

## Deploy
Drag this folder onto https://app.netlify.com/drop — done. Or push to GitHub and import at vercel.com.
